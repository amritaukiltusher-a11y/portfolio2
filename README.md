# Amrita Ukil Tusher — Portfolio

A single-page portfolio website for Amrita Ukil Tusher, Freelance SEO Expert.

## Structure
- `index.html` — the full page (HTML + inline CSS, no build tools needed)
- `profile.jpg` — profile photo

## Run locally
Just open `index.html` in any browser. No server, no build step, no dependencies.

## Deploy to GitHub Pages
1. Push this repo to GitHub (see steps in the chat where this was shared).
2. On GitHub, go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Branch: `main`, folder: `/ (root)` → **Save**.
5. Wait ~1 minute — GitHub will show the live URL at the top of that same Pages settings page.

Live URL will look like:
- `https://<username>.github.io/<repo-name>/` (project site), or
- `https://<username>.github.io/` (if the repo is named exactly `<username>.github.io`)
